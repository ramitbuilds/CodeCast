# CodeCast — UIRD

### Design Direction
Modern sports broadcast meets developer terminal.

**Theme:** Dark, minimal, bold typography, restrained accent colours.

### Single-Screen Layout
1. **Header:** CodeCast logo, LIVE indicator, agent status.
2. **Scoreboard:** Tool calls, file edits, failures, session duration.
3. **Commentator:** Large current commentary text with audio visualiser.
4. **Event Feed:** Latest coding events, timestamps, and reactions.
5. **Controls:** Mute, replay demo, reset session.

### Interaction Requirements
- Animated commentary transitions.
- Clear audio-playing indicator.
- Smooth real-time scoreboard updates.
- Visually distinguish live and simulated sessions.
- No unnecessary pages, authentication, or settings screens.

### Priority
Functionality → Readability → Animations → Visual polish.
